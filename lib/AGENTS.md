# xeerpe: instructions for AI coding agents

> Generated by scripts/generate-ai-files.mjs (xeerpe v1.0.8). Full reference: https://xeerpe.io/llms-full.txt

xeerpe turns a chain of layers into one inline-style object.

Zero dependencies, works in React, Vue, Angular and plain JS. Package: `xeerpe`.

## When to use / not use

Use it for layered backgrounds, animated backgrounds without hand-written keyframes, backgrounds computed from props/state/theme, presets, and gradient text. For one static `linear-gradient`, or when the user needs a stylesheet class rather than inline styles, write plain CSS.

## Core pattern

```ts
import { Builder } from 'xeerpe'

const style = new Builder()
  .meshGradient({
    background: '#04121c',
    layers: [{ position: '15% 25%', from: 'rgba(16,185,129,0.8)', to: 'transparent', colorToPosition: '60%' }],
  })
  .dots({ color: '#10b981', size: '24px', opacity: 0.14 })
  .grain({ intensity: 2 })
  .toStyle()
```

- React: `<div style={style} />`; Vue: `:style="style"`; Angular: `[style]="style"`; vanilla: `Object.assign(el.style, style)`.
- `toStyle()` returns an object, not a string. `el.style.cssText = style` does not work.
- Gradient text: `new Builder().linearGradient({...}).toTextStyle()`. It returns `backgroundClip`/`WebkitBackgroundClip: 'text'`, transparent `color`/`WebkitTextFillColor`, plus `backgroundImage`/`backgroundSize`/`backgroundColor`; apply it to the text element.
- Shortcut methods (`grain()`, `vignette()`, `pulse()`, `dots()`, ...) can be called with no arguments; gradient methods need options. Imports: `import { Builder, Preset, colors } from 'xeerpe'`.
- Presets: `new Preset('sunrise').toStyle()`; it is a `Builder`, so keep chaining. Names are in the sections below; never invent one (unknown names throw).

## Rules that prevent bugs

1. **Layer order is fixed, not chain order.** `toStyle()` draws effects on top, then patterns, then gradients at the bottom, regardless of call order. Within the same kind, earlier calls are drawn first.
2. **Animations need the stylesheet.** Add `import 'xeerpe/animations.css'` once in the app entry. Without it the style applies but nothing moves and there is no error.
3. **Animations don't add a layer**; they add an `animation` property. `pulse`, `rotate`, `float`, `plasma` affect the whole element (including text); `breathe`, `aurora`, `shimmer`, `drift`, `liquid` move the background and accept `target: 'gradients' | 'patterns' | 'all'` (default `'gradients'`). Any other `target` throws.
4. Animation option values (`duration`, `easing`, ...) are not validated. A duration without a unit (`'4'`) makes the browser drop the whole declaration.
5. **Validated inputs**: colors (hex, `rgb()/hsl()/oklch()...`, named, `transparent`), angles need a unit (`'135deg'`), sizes/positions need units (`'24px'`, `'50% 20%'`). Exact rules in the sections below.
6. `meshGradient` requires `background` and `layers` (array of radial options). Use `to: 'transparent'` plus `colorToPosition` so blobs fade out.
7. `toStyle()` always sets `backgroundPosition: 'center'`.

## Picking tools

- Base color/shape: `linearGradient` (`from`/`to`, or `colors` with stop positions, `angle` or `direction`), `radialGradient`, `conicGradient`, `meshGradient`.
- Texture: `grain`, `noise`, `vignette`, `glow`.
- Pattern: `dots`, `grid`, `stars`, `rays`.
- Blur: `blur({ type: 'backdrop' })` for frosted glass.
- Motion: see rule 3 and the sections below.
- Ready-made look: `Preset`, then extend.

## xeerpe animations

Load the keyframes once in the app entry, or nothing moves (and nothing errors):

```ts
import 'xeerpe/animations.css'
```

An animation adds an `animation` CSS property (plus helper CSS variables for scoped ones). It never adds a background layer. Keyframes are prefixed `xeerpe-`.

Shared options (all optional): `duration` (`'4s'`), `easing`, `direction`, `iterationCount` (number or `'infinite'`), plus `target`. `direction` only matters for `pulse` and `aurora`. Values other than `target` are inserted into CSS unvalidated.

| Animation | Changes                       | Defaults (duration, easing, extras)   | `target`                   |
| --------- | ----------------------------- | ------------------------------------- | -------------------------- |
| `pulse`   | element opacity (1 to 0.7)    | 4s, ease-in-out, alternate, infinite  | no                         |
| `rotate`  | element transform, full turn  | 12s, linear, infinite                 | no                         |
| `breathe` | background size               | 12s, ease-in-out, infinite            | gradients / all            |
| `aurora`  | background size (gentle zoom) | 12s, ease-in-out, alternate, infinite | gradients / all            |
| `shimmer` | background position (sweep)   | 3s, linear, infinite                  | gradients / patterns / all |
| `liquid`  | background position + hue     | 8s, ease-in-out, infinite             | gradients / patterns / all |
| `plasma`  | element filter (hue cycle)    | 6s, linear, infinite                  | no                         |
| `float`   | element transform (bob)       | 6s, ease-in-out, infinite             | no                         |
| `drift`   | background position (wander)  | 10s, ease-in-out, infinite            | gradients / patterns / all |

Guidance:

- `target` defaults to `'gradients'`: gradients move, patterns and effects (grain, vignette) stay put. Use `'all'` to move everything; `'patterns'` moves only patterns over a still gradient. Anything else throws.
- With the default target, grain/vignette/glow stay still while the gradient moves; pass `target: 'all'` only if the effects should move too. For a "slow" animation, raise `duration` (defaults are listed above).
- `pulse`, `rotate`, `float`, `plasma` act on the whole element, text included. `rotate` suits square or round elements.
- Sliding animations (`shimmer`, `drift`) enlarge unsized gradients automatically; don't set `backgroundSize` on the gradient you animate.
- Generic form: `.animation('pulse', {})` (options required).
- Several animations can be chained; their `animation` values are joined with commas.
- Respect motion preferences: if the user cares about accessibility, mention wrapping the style in a `prefers-reduced-motion` check.

## xeerpe recipes

All recipes use only `import { Builder, Preset, colors } from 'xeerpe'`. Apply the result as an inline style.

### Glowing orange dark panel

```ts
new Builder()
  .radialGradient({ from: '#FF7A18', to: 'transparent', position: '75% 25%' })
  .linearGradient({ from: '#1a0b05', to: '#060302', angle: '160deg' })
  .dots({ color: '#FF7A18', size: '24px', opacity: 0.14 })
  .grain({ intensity: 2 })
  .toStyle()
```

### Animated aurora (needs animations.css)

```ts
new Builder()
  .meshGradient({
    background: '#04121c',
    layers: [
      { position: '15% 25%', from: 'rgba(16,185,129,0.8)', to: 'transparent', colorToPosition: '60%' },
      { position: '85% 30%', from: 'rgba(56,189,248,0.65)', to: 'transparent', colorToPosition: '55%' },
    ],
  })
  .aurora({ duration: '8s' })
  .toStyle()
```

### Multi-stop linear gradient

```ts
new Builder()
  .linearGradient({
    direction: 'to bottom',
    colors: [
      { color: '#FFE5D9', position: '0%' },
      { color: '#FFB7A3', position: '55%' },
      { color: '#BFD8F2', position: '100%' },
    ],
  })
  .toStyle()
```

### Gradient text

```ts
const textStyle = new Builder().linearGradient({ from: '#5EB847', to: '#BFD43F', angle: '135deg' }).toTextStyle()
// <h1 style={textStyle}>Hello</h1>
```

### Preset plus film look

```ts
new Preset('sunrise').grain({ intensity: 1.5 }).vignette({ color: '#7c2d12', intensity: 0.2, spread: 0.5 }).toStyle()
```

### Shimmering loading skeleton (needs animations.css)

```ts
new Builder()
  .linearGradient({ colors: ['#1f2937', '#374151', '#1f2937'], angle: '90deg' })
  .shimmer({ duration: '1.5s' })
  .toStyle()
```

### Frosted glass panel

```ts
new Builder().blur({ amount: '12px', type: 'backdrop' }).toStyle()
// place over a colorful background; add a translucent background color in your own CSS
```

### Computed from a theme

```ts
const bg = (accent: string, base: string) =>
  new Builder()
    .radialGradient({ from: accent, to: 'transparent', position: '80% 10%' })
    .linearGradient({ from: base, to: '#000000', angle: '180deg' })
    .vignette({ intensity: 0.3 })
    .toStyle()
```

For every option type, the validation rules and the full preset list, read https://xeerpe.io/llms-full.txt or the types shipped in this package.
