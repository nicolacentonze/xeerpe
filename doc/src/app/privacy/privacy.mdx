# Privacy

Last updated: October 2026.

xeerpe is an open source library for building CSS backgrounds. This page explains what the xeerpe library, its Claude Code skill and this website do with data.

## The library and the AI assistant files

The `xeerpe` npm package runs entirely on your machine or in your users' browsers. It does not collect, store or send any data, and it makes no network requests.

The same applies to the files that help AI assistants write xeerpe code:

- the **Claude Code plugin and skill**, which consist only of text instructions and an icon. They contain no code, hooks or MCP servers, and they do not read your files, credentials or personal data;
- the **`AGENTS.md`** file shipped in the npm package;
- the **`llms.txt`** and **`llms-full.txt`** files served by this website.

When an AI assistant reads these files, it is that assistant, and the service that runs it, that handles your conversation. Their privacy policies apply to that, not this page.

## This website

This website collects no personal data itself: it has no user accounts, forms, analytics or advertising, and it sets no cookies.

The site is hosted by [Vercel](https://vercel.com). Like most hosting providers, Vercel may record basic technical information about each visit, such as your IP address and the time of the request, to run and protect the service. I do not receive or use this information. See [Vercel's privacy policy](https://vercel.com/legal/privacy-policy) for details.

## Links to other services

This site and the library link to GitHub and npm. Those services have their own privacy policies and are not controlled by xeerpe.
