# Changelog

Every notable change to xeerpe, grouped by release range. The newest releases come first.

<small>1.0.7 – 1.0.8</small>

## AI assistant support

xeerpe now comes with instructions that help AI assistants write xeerpe code correctly.

### Added

- **`AGENTS.md`** in the npm package, for coding assistants such as Codex, Cursor and GitHub Copilot that read it from the root of your project
- **`llms-full.txt`** on xeerpe.io, which gathers the API, the validation rules, some recipes and every preset in one file, so you can share it with ChatGPT, Perplexity or any other chat assistant

---

<small>1.0.5 – 1.0.6</small>

## Bug fixes

### Fixed

- **Mesh gradients**: background sizes now match every CSS image in a mesh gradient, and the layers you add after it

### Changed

- New releases are now published to npm with provenance

---

<small data-tone="blue">1.0.0</small>

## Stable release

xeerpe 1.0.0 is the first stable release. The public API is now covered by semantic versioning.

### Added

- **Patterns**: `stars` and `rays`
- Full documentation for gradients, patterns, effects, filters and animations at xeerpe.io


---

<small>0.0.17 – 0.0.19</small>

## Presets, validation and animations

### Added

- **Presets**: ready-made backgrounds built on the named color palette
- **Animations**: `liquid`, `plasma`, `float`, `drift` and `shimmer`
- **Validation** for colors, angles, background sizes, CSS positions, directions, radial options and color stop positions
- `transparent` as the default color, with shared `resolveColor` and color stop helpers

### Fixed

- Inconsistent color handling in patterns

---

<small>0.0.13 – 0.0.16</small>

## Animations and refinements

### Added

- **Animations**: new `aurora` and a reworked `breathe`
- **Builder**: multiple filters, backdrop filters and animations now combine in a single chain
- Cleaner `toTextStyle()` output, typed and limited to the defined properties
- Updated README

### Fixed

- Default values for options
- Glitches in the `aurora` animation
- Style output when no pattern or shadow layers were set

---

<small>0.0.5 – 0.0.12</small>

## Effects, patterns and animation

### Added

- **Effects**: `noise`, `vignette`, `grain` (animated with `feTurbulence`) and `glow`
- **Filters**: `blur`
- **Patterns**: `dots` and `grid`
- **Animations**: `pulse`, `rotate` and `breathe`

### Fixed

- Issues with the `glow` effect
- Build and import errors when used from external projects

---

<small>0.0.1 – 0.0.4</small>

## Foundations

### Added

- Chainable `Builder` API
- **Gradients**: `linear`, `radial`, `conic` and `mesh`
- A first version of the blur filter and the grid pattern
- First validation layer
- Palette of 100 named colors
- README, license and npm package setup

### Fixed

- Package renamed to satisfy the npm naming rules
- A broken import and small typos
