Presets are ready-made backgrounds. Pick one by name and you get a complete style in a single line of code. This page documents the available presets, how to build on top of them and the color palette they use.

## Overview

Create a preset with the `Preset` class and the name of the preset, then call `toStyle()` exactly as you would on a `Builder`.

```ts
import { Preset } from 'xeerpe'

const style = new Preset('sunrise').toStyle()
```

`Preset` extends `Builder`: it is a builder that already contains the layers of the preset. Everything you can do with a `Builder`, you can also do with a preset.

xeerpe ships two presets: `sunrise` and `northern-lights`.

<Prop name="name" type="string" required>

    The name of the preset, either `'sunrise'` or `'northern-lights'`. Names are case-sensitive.

    TypeScript does not check the name, because the type is a plain `string`. An unknown name throws an error with the message `Preset "<name>" not found` as soon as the preset is created.

</Prop>

## sunrise

A soft vertical gradient from warm peach at the top to pale sky blue at the bottom. It is a light background, so it pairs well with dark text.

<XeerpeDemo example="preset-sunrise" />

```ts
new Preset('sunrise').toStyle()
```

### How sunrise is built

`sunrise` is a single linear gradient with four color stops.

```ts
new Builder()
  .linearGradient({
    colors: [
      { color: '#FFE5D9', position: '0%' },
      { color: '#FFCDB6', position: '35%' },
      { color: '#FFB7A3', position: '55%' },
      { color: '#BFD8F2', position: '100%' },
    ],
    direction: 'to bottom',
  })
  .toStyle()
```

## northern-lights

A dark navy base covered by six overlapping blobs of green, teal and violet, like an aurora in the night sky. It includes a slow, five-second `aurora` animation that gently zooms the background in and out.

> **Note:** the animation needs the xeerpe stylesheet. Without it the preset still renders, but it does not move. See [Add the stylesheet](/guide/installation#add-the-stylesheet).

<XeerpeDemo example="preset-northern-lights" />

```ts
new Preset('northern-lights').toStyle()
```

### How northern-lights is built

`northern-lights` is a mesh gradient built with colors from the [palette](#colors), plus an `aurora` animation.

```ts
import { Builder, colors } from 'xeerpe'

new Builder()
  .meshGradient({
    background: '#050914',
    layers: [
      {
        position: '15% 15%',
        from: colors.malachite,
        to: 'transparent',
        colorFromPosition: '0px',
        colorToPosition: '55%',
      },
      {
        position: '40% 8%',
        from: colors.celadon,
        to: 'transparent',
        colorFromPosition: '0px',
        colorToPosition: '55%',
      },
      {
        position: '68% 18%',
        from: colors.verdigris,
        to: 'transparent',
        colorFromPosition: '0px',
        colorToPosition: '50%',
      },
      {
        position: '85% 30%',
        from: colors.malachite,
        to: 'transparent',
        colorFromPosition: '0px',
        colorToPosition: '50%',
      },
      {
        position: '45% 50%',
        from: colors.amethyst,
        to: 'transparent',
        colorFromPosition: '0px',
        colorToPosition: '45%',
      },
      {
        position: '20% 65%',
        from: colors.wisteria,
        to: 'transparent',
        colorFromPosition: '0px',
        colorToPosition: '40%',
      },
    ],
  })
  .aurora({ duration: '5s' })
  .toStyle()
```

## Extending a preset

Because a preset is a builder, you can keep chaining after it. Effects, patterns, filters and animations all work, and they are drawn on top of the preset.

### Examples

#### Film look

Grain and a warm vignette give the soft sunrise a photographic feel.

<XeerpeDemo example="preset-sunrise-film" />

```ts
new Preset('sunrise')
  .grain({ intensity: 1.5 })
  .vignette({
    color: '#7c2d12',
    intensity: 0.2,
    spread: 0.5,
  })
  .toStyle()
```

#### Textured night

A light noise layer and a vignette add depth to the northern lights.

<XeerpeDemo example="preset-lights-textured" />

```ts
new Preset('northern-lights')
  .noise({ opacity: 0.15 })
  .vignette({
    intensity: 0.5,
    spread: 0.4,
  })
  .toStyle()
```

### Good to know

- **Effects and patterns** are always drawn above gradients, so they work on any preset.
- **A gradient added after a preset** is drawn below the preset's gradient, because the layers added first sit on top. On `sunrise`, which is fully opaque, a second gradient would be hidden.
- **An animation added after a preset** runs together with the preset's own animation. For example, `new Preset('northern-lights').float()` runs both `aurora` and `float`.

## Colors

xeerpe also exports `colors`, the palette used by its presets: 100 named colors, each one a six-digit hex string. Use them anywhere a color is accepted.

```ts
import { Builder, colors } from 'xeerpe'

const style = new Builder()
  .linearGradient({
    from: colors.inkwell,
    to: colors.obsidian,
  })
  .toStyle()
```
