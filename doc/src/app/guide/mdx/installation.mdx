xeerpe is published on npm and has no runtime dependencies. Install it with your package manager, then add the stylesheet if you plan to use animations.

## Install the package

```bash title="npm"
npm install xeerpe
```

```bash title="Yarn"
yarn add xeerpe
```

```bash title="pnpm"
pnpm add xeerpe
```

## Add the stylesheet

Gradients, patterns, effects and filters work without any extra setup. Animations are different: their keyframes live in `animations.css`, which you import once in your project.

> **Note:** without the stylesheet the animation styles are still applied, but nothing moves and the browser reports no error. This also applies to presets that include an animation, such as `northern-lights`.

```ts title="JavaScript or TypeScript entry file"
import 'xeerpe/animations.css'
```

```css title="CSS"
@import 'xeerpe/animations.css';
```

```scss title="SCSS"
@use 'xeerpe/animations.css';
```

In Angular, add `node_modules/xeerpe/dist/animations.css` to the `styles` array of your project in `angular.json`.
