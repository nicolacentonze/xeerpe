## Installation

### npm

```bash
npm install xeerpe
```

### Yarn

```bash
yarn add xeerpe
```

## Styles

If you want to use the animation features in `xeerpe`, import the `animations.css` file into your project.

### CSS

```css
@import 'xeerpe/animations.css';
```

### SCSS

```scss
@use 'xeerpe/animations.css';
```
