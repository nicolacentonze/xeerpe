More than 200 ready-made backgrounds, from polished gold to a night in the jungle. Every preset is one line of code: pick one, click it to copy the snippet, and paste it into your project.

```ts
import { Preset } from 'xeerpe'

const style = new Preset('gold').toStyle()
```

A preset is a regular `Builder`, so you can keep chaining effects, patterns, filters and animations after it. See [Extending a preset](/guide/presets#extending-a-preset).

> **Note:** the presets under [Motion](#motion), and `northern-lights`, are animated. They need the xeerpe stylesheet, otherwise they render without moving. See [Add the stylesheet](/guide/installation#add-the-stylesheet).

Every name is also available in code, so you can build your own picker:

```ts
import { presetCategories, presetNames } from 'xeerpe'

presetCategories.metals // ['gold', 'antique-gold', 'rose-gold', ...]
presetNames.length      // every preset, in every category
```
